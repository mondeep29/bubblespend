# BubbleSpend Android

BubbleSpend is a native Android, local-first expense tracker built with Kotlin and Jetpack Compose. It records expenses and helps one person understand spending, fully offline.

## Build and test

See [Android build setup](docs/build-setup.md) for JDK/SDK requirements and local verification commands. Required device checks run on a connected physical Android device.

## Project details and status

Read [the product brief](docs/product/product-brief.md) for scope and [completion status](docs/project-status.md) for finished features, remaining work, and recorded verification. Technical details remain in [specifications](docs/specs/), [architecture decisions](docs/adr/), [product decisions](docs/decisions.md), and [coding standards](docs/coding-standards.md).

Cloud sync, accounts, bank integrations, receipt OCR, AI categorization, budgets, recurring expenses, and notifications are outside the MVP.
