# Android release checklist

- [ ] All MVP specifications are Implemented and criteria map to passing tests.
- [ ] CI passes from a clean checkout; release build and signed source revision recorded.
- [ ] Android overlay grant, denial, revocation, lock-screen privacy, process death, and restart behavior verified on representative devices.
- [ ] Dashboard and analytics reconcile against seeded reference data.
- [ ] Migration and export/restore tests pass with a production-scale fixture.
- [ ] TalkBack, large/bold text, high contrast, reduced motion, and touch-target audits pass.
- [ ] Offline use and app restart preserve successful mutations.
- [ ] Release logs contain no financial, personal, backup, or credential content.
- [ ] Privacy copy and permission education match shipped behavior.
- [ ] Known limitations and recovery procedure are documented.
