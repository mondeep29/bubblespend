# BT-001: Approve product foundation

**Objective:** Finalize product brief, glossary, non-functional requirements, MVP boundaries, and state inventory.

**Inputs:** `docs/product/*`, `docs/decisions.md`, supplied roadmap. **Allowed scope:** product docs and decision log. **Out of scope:** application code and dependency selection.

**Required proof:** Review every MVP outcome against a user journey, edge/error state, privacy rule, and accessibility rule. Record unresolved owner decisions. Documentation task: red test not applicable.

**Acceptance:** Scope and measurable release criteria are internally consistent; owner-visible decisions are explicit. **Verification:** `rg -n 'Draft|Proposed|Open questions|D-0' docs/product docs/decisions.md` and manual review. **Deliverables:** updated docs and `workflow/evidence/BT-001.md`.
