# BT-014: Deliver Android floating shortcut

**Objective:** Productionize opt-in fast entry above other apps.

**Inputs:** approved SPEC-005, overlay proof, ADR-004, expense use case. **Allowed scope:** floating shortcut feature, Android service/window adapter, settings, platform tests. **Out of scope:** startup without consent and unrelated background work.

**Required tests first:** State transitions, position clamping/rotation, permission grant/deny/revoke, exactly-once save, lifecycle recovery, dashboard open, lock-screen privacy, TalkBack. Capture red result.

**Acceptance:** A real-device run proves the approved lifecycle; denial does not affect normal app use; disable removes overlay. **Verification:** `./gradlew spotlessCheck lint testDebugUnitTest connectedDebugAndroidTest assembleDebug` plus proof scenarios on recorded devices. **Deliverables:** code, tests, updated proof, mapping, evidence.
