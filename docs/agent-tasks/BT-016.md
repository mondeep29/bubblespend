# BT-016: Deliver backup and restore

**Objective:** Export and restore local data without partial overwrite.

**Inputs:** approved SPEC-007, ADR-002, BT-007 Room database. **Allowed scope:** backup format/validator/repository, Android document adapter, UI, tests. **Out of scope:** cloud backup.

**Required tests first:** Round trip, unsupported/corrupt/duplicate/missing-reference input, preview counts, transactional rollback, production-scale fixture, privacy. Capture red result.

**Acceptance:** Validation precedes mutation; failure leaves live data unchanged; restored totals match exported data. **Verification:** `./gradlew spotlessCheck lint testDebugUnitTest connectedDebugAndroidTest assembleDebug`. **Deliverables:** format version, code, tests, recovery docs, mapping, evidence.
