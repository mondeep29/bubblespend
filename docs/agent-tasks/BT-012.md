# BT-012: Approve analytics specification

**Objective:** Define buckets, comparisons, insight thresholds, and accessible visual behavior.

**Inputs:** SPEC-004 draft, analytics proof, approved SPEC-003, ADR-003. **Allowed scope:** SPEC-004 and decision log. **Out of scope:** production analytics code.

**Required proof:** Exact reference datasets for zero days, rounded shares, previous periods, and each insight rule; no-data cases. Documentation task: red test not applicable.

**Acceptance:** SPEC-004 Approved with stable criteria and traceable datasets. **Verification:** manual calculation review. **Deliverables:** approved spec, fixtures, evidence.
