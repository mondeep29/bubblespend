# BT-002: Approve architecture and data decisions

**Objective:** Validate ADR-001 through ADR-005 and lock native Android stack choices.

**Inputs:** BT-001 evidence, ADRs, product brief. **Allowed scope:** `docs/adr/`, decision log. **Out of scope:** feature UI and production database.

**Required proof:** Check module direction, Room repository contracts, DataStore split, money/time invariants, overlay boundary, future sync metadata. Record selected dependency versions for BT-005 or explicitly delegate version locking there. Documentation task: red test not applicable.

**Acceptance:** ADRs needed for foundation are Approved; blocking choices remain visible. **Verification:** manual ADR review and `rg -n 'Status|Room|minor units|UTC|overlay' docs/adr`. **Deliverables:** ADR changes and evidence.
